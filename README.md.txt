# 3ayelti 👨‍👩‍👧‍👦

Plateforme web de gestion des tâches et des finances familiales.

## 🎯 Objectif
Aider les familles à :
- Organiser les tâches domestiques
- Gérer le budget familial
- Répartir les factures
- Motiver les enfants avec des récompenses

## 🛠️ Technologies utilisées
- HTML / CSS
- JavaScript
- PHP
- MySQL
- WAMP Server

## ⚙️ Installation
1. Installer WAMP
2. Copier le projet dans `www`
3. Créer la base de données MySQL
4. Importer le fichier SQL
5. Lancer : `http://localhost/mon_projet`
